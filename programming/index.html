01 — Curriculum

入門カリキュラム

1日1テーマ、30日で一巡する自習用カリキュラムです。各日は「解説 → 練習 → 理解度チェック」の順に進み、理解度チェックに正解すると確認コード付きの画面が表示されます。

Curriculum — 30 days

プログラミング入門30日

Webページの骨組みであるHTMLから始めて、CSSによるデザイン、JavaScriptによる動きのあるページ、そしてPythonでのデータ処理・グラフ描画まで。テキストエディタとブラウザがあれば今日から始められます。

  • 解説 読む
  • 練習 手を動かす
  • 理解度チェック 確認コードを取得
目次を開く →
  1. 第1部 HTMLWebページの骨組みをつくる Day 1–8
  2. 第2部 HTML / CSS見た目を整え、1枚のページを完成させる Day 9–16
  3. 第3部 JavaScriptページに動きをつけ、プログラミングの基本を学ぶ Day 17–24
  4. 第4部 PythonJupyterLab でデータ処理とグラフ描画に入門 Day 25–30

02 — Environment

オンライン実習環境

ブラウザだけで使える Python／Jupyter 環境です。インストールは不要で、第4部（Python）の学習や講義中のAI演習でも利用します。

JupyterLab

JupyterLab 実習環境

ブラウザで動作し、インストールは不要です。ノートブックを新規作成し、セルにコードを書いて Shift+Enter で実行します。

05 — How to study

学び方のヒント

本講義のAIポリシー「使う・検証する・区別する」は、プログラミングの学習でもそのまま当てはまります。

  • 順番に、少しずつ30日カリキュラムは前の日の内容を前提に進みます。1日1テーマのペースで、飛ばさずに進めるのが近道です。
  • 必ず自分で動かすサンプルコードは読むだけでなく、実習環境に貼り付けて実行し、数値や文字を書き換えて結果の変化を確かめましょう。
  • AIに聞き、自分で検証するエラーの意味やコードの説明は生成AIに尋ねて構いません。ただし、答えを鵜呑みにせず、実際に動かして確かめてから採用してください。
