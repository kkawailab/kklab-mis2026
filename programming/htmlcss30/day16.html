第2部 HTML/CSS — Day 16 / 30

演習:自己紹介ページ

Goal — 今日のゴール 第2部 8/8

第1部・第2部の内容を組み合わせて、1枚のページを完成させる。

解説を読んだら練習に取り組み、最後に理解度チェックで確認コードを取得します。

ここまでの内容を総動員して、自己紹介ページを作りましょう。要件は次の5つです。①見出しと段落 ②画像 ③リスト ④カード風デザイン ⑤スマホ対応(viewport)。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>自己紹介</title>
  <style>
    /* ここに自分のスタイルを書く */
  </style>
</head>
<body>
  <div class="card">
    <h1>名前</h1>
    <p>ひとこと自己紹介</p>
  </div>
</body>
</html>
