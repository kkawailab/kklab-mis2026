第3部 JavaScript — Day 19 / 30

条件分岐

Goal — 今日のゴール 第3部 3/8

if・else if・else で、条件によって処理を変えられる。

解説を読んだら練習に取り組み、最後に理解度チェックで確認コードを取得します。

const score = 75;

if (score >= 80) {
  console.log("よくできました!");
} else if (score >= 60) {
  console.log("合格です");
} else {
  console.log("再チャレンジ!");
}

比較には >=(以上)、<=(以下)、===(等しい)、!==(等しくない)を使います。「等しい」は = を3つ重ねる点に注意しましょう(= 1つは代入の意味です)。

今日の練習

score の値を変えて実行し、3パターンすべてのメッセージが表示されることを確認しましょう。

模範解答を見る 
const score = 85;  // 85 → よくできました! / 70 → 合格です / 40 → 再チャレンジ!

if (score >= 80) {
  console.log("よくできました!");
} else if (score >= 60) {
  console.log("合格です");
} else {
  console.log("再チャレンジ!");
}

score を書き換えて3回実行し、それぞれのメッセージが出れば成功です。境目の 80・60・59 で試すと理解が深まります。
